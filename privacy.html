Política de privacidad de CLIPLAB

Última actualización: 4 de noviembre de 2026

CLIPLAB es una aplicación personal desarrollada y usada por Alejandro López (en adelante, «el responsable») para gestionar su propio canal de YouTube. Esta política explica qué datos trata la aplicación, para qué y cómo se protegen.

1. Responsable y contacto

Alejandro López · jandrialex69@gmail.com

2. Datos de Google a los que accede

Cuando el usuario conecta su cuenta de Google mediante OAuth 2.0, CLIPLAB puede acceder, según los permisos que el usuario conceda, a:

  • YouTube Data API (youtube.upload, youtube.readonly, youtube.force-ssl): subir vídeos al canal del usuario, leer la lista de sus vídeos y sus datos públicos, y gestionar los metadatos y subtítulos de esos vídeos.
  • YouTube Analytics API (yt-analytics.readonly, yt-analytics-monetary.readonly): leer estadísticas del canal (visualizaciones, retención, ingresos estimados) en solo lectura.
  • AdSense Management API (adsense.readonly), solo si el usuario lo activa: leer en solo lectura los ingresos de su cuenta.

CLIPLAB no accede a correos, contactos, archivos de Drive ni a ningún otro dato de la cuenta de Google.

3. Para qué se usan

  • Publicar en el canal del usuario los clips que él mismo ha creado y aprobado.
  • Mostrarle al usuario el rendimiento de sus clips para decidir qué publicar.

Los datos no se usan para publicidad, no se venden, no se transfieren a terceros y no se usan para entrenar modelos de inteligencia artificial generalistas.

4. Dónde se guardan

Los tokens de acceso de Google y las estadísticas se guardan solo en el ordenador del usuario (archivos locales y una base de datos SQLite), no en servidores de CLIPLAB. Los tokens no se publican ni se comparten. Las transcripciones de audio pueden enviarse a un proveedor de transcripción elegido por el usuario (por ejemplo, Groq) solo con el audio de los vídeos del propio usuario; nunca se envían datos de la cuenta de Google.

5. Conservación y eliminación

Los datos se conservan mientras el usuario use la aplicación. El usuario puede borrarlos en cualquier momento eliminando los archivos locales de CLIPLAB y revocar el acceso desde myaccount.google.com/permissions. También puede pedir ayuda escribiendo a la dirección de contacto.

6. Cumplimiento de la política de datos de Google

El uso que hace CLIPLAB de la información recibida de las API de Google se ajusta a la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado (Limited Use). CLIPLAB usa además los servicios de API de YouTube; al usarla, el usuario acepta las Condiciones del servicio de YouTube y la Política de privacidad de Google.

7. Seguridad

Las credenciales se guardan en variables de entorno o en archivos locales excluidos de cualquier repositorio, y la aplicación solo usa las API oficiales de Google, nunca automatización del navegador con cookies.

8. Cambios

Si esta política cambia, se actualizará esta página y su fecha.

English summary

CLIPLAB is a personal tool used by its owner to upload his own videos to his own YouTube channel and read that channel's analytics. It accesses only the YouTube Data API, YouTube Analytics API and, optionally, AdSense Management API (read-only), using the scopes listed above. Google user data is stored only on the owner's computer, is never sold, shared with third parties or used for advertising, and can be revoked at any time at myaccount.google.com/permissions. CLIPLAB's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Contact: jandrialex69@gmail.com.
